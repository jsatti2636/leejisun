# 웨이메이커360 교육청 점검대비

- `docs/감사대비_연구보고서.md`: 별빛연구소 '학원 안심장부 Lite' 분석, 학원법 점검 기준, 적용안
- `tools/audit-ledger.html`: 원장님 전용 점검대비 장부 (크롬에서 열면 바로 사용, 자료는 브라우저에만 저장)
  - [엑셀 일괄등록] 메뉴에서 양식을 받아 교습비·강사·수강생·수납을 한 번에 올립니다 (처음 쓸 때 인터넷 필요).
  - [홈페이지 게시] 메뉴에서 홈페이지용 교습비·반환기준 게시 코드를 만듭니다.
- `tools/worksheet-maker.html`: 교재 보충자료 시험지 만들기 (크롬·엣지에서 열면 바로 사용, 자료는 브라우저에만 저장)
  - [자료 올리기]에서 출판사 보충자료의 워드(.docx) 파일이나 ZIP을 고르면 문제 파일과 `_정답` 파일을 짝지어 문항별로 정리합니다. 폴더째로 골라도 됩니다.
  - [시험지 만들기]에서 교재(레벨)와 단원을 고르고 전부/무작위/직접 고르기로 문항을 뽑아 문제지와 답안지를 따로 인쇄합니다.
  - 한글(.hwp)·PDF는 읽지 못하므로 같은 자료의 (워드) 버전을 받아 올려 주세요. 출판사 자료는 이 저장소에 올리지 않습니다.
