# 교육청 학원 점검 대비: '학원 안심장부 Lite' 분석과 웨이메이커360 적용안

작성일: 2026-09-30

## 1. 결론 요약

- **할 수 있습니다.** '학원 안심장부 Lite'(별빛연구소)는 서버 없이 HTML 파일 하나로 돌아가는 장부 도구입니다. 데이터는 브라우저(localStorage)에 저장되고, 인터넷은 라이선스 인증 때만 씁니다. 같은 방식으로 우리 도구를 직접 만들 수 있고, `tools/audit-ledger.html`에 프로토타입을 만들었습니다.
- **코드는 베끼지 않았습니다.** 별빛연구소 파일은 유료 판매 상품(스마트스토어)입니다. 구조와 아이디어만 참고했고, 코드와 디자인은 처음부터 새로 작성했습니다.
- **원본보다 점검 대응을 강화했습니다.** 실제 점검 위반 순위(아래 3절)에 맞춰 교습비 변경 이력, 강사 명부와 성범죄·아동학대 조회 기록, 법정 반환 계산기, 초과징수 차단 기능을 넣었습니다.
- **홈페이지에는 '장부'를 올리지 말고 '교습비 게시'를 올리세요.** 장부는 원장님 전용 도구입니다. 학부모에게 보이는 홈페이지에 필요한 것은 학원법 제15조가 요구하는 **교습비·반환기준 게시**이고, 장부 도구가 이 게시용 코드를 자동으로 만들어 줍니다.

## 2. 별빛연구소 '학원 안심장부 Lite' 분석

### 구조
| 항목 | 내용 |
|---|---|
| 형태 | HTML 파일 1개(약 72KB), 설치 없음 |
| 저장 | 브라우저 localStorage (`academyLedgerLite_v1`) |
| 인증 | Google Apps Script 웹앱에 JSONP로 이용코드를 확인하고, 코드 하나당 PC 2대까지 등록 |
| 판매 | 무료판은 학생 10명까지. 엑셀 일괄등록, 출납부 출력, 다학원 관리는 정식판 |

### 기능 (메뉴 8개)
1. 오늘의 확인: 재원생, 월 수납·지출, '확인 필요' 건수
2. 시작 설정: 학원 정보, 교습비 기준(반명·과목·월 교습비)
3. 학생 관리: 등록·퇴원 처리
4. 원비 결제: 정상 / 할인·감액 / 일할계산 / 환불, 사유 입력
5. 현금출납부: 수납·환불 자동 반영, 지출 수기 입력
6. 교육비 영수증: 결제 1건당 영수증 출력
7. 수강생대장: 시행규칙 별지 서식 모양으로 출력
8. 월·연간 마감: 자동 점검(교습비 불일치·사유 누락), JSON 백업

### 잘한 점
- 수납 한 번으로 영수증, 출납부, 대시보드가 한꺼번에 채워집니다(단일 원천).
- 등록 교습비와 결제액이 다르면 행 색깔로 표시합니다.
- 비정상 수납(할인·환불)에는 사유를 필수로 받아, 점검 때 소명 근거가 남습니다.

### 한계 (점검 관점)
| 한계 | 왜 문제인가 |
|---|---|
| 교습비 **변경 이력이 없음**(반마다 금액 1개) | 교습비를 올리면 과거 수납이 전부 '불일치'로 바뀝니다. 2026 서울 점검 위반 1위인 '교습비 변경 미등록'을 추적할 수 없습니다. |
| 초과징수를 **막지 않음** | 차액을 색으로만 표시하고, '직접 확인'을 누르면 경고가 사라집니다. |
| 일할계산이 **월 12회로 고정** | 주 2회 반(월 8회)은 금액이 틀리게 나옵니다. |
| 환불에 **법정 반환기준 계산이 없음** | 시행령 [별표 4]보다 적게 돌려주면 위반인데, 이를 확인하지 않습니다. |
| **강사 명부가 없음** | 성범죄·아동학대 전력 조회와 채용 통보는 점검 단골 항목입니다. |
| 날짜를 UTC로 계산 | 한국 시간 오전 9시 전에는 '어제'로 기록됩니다. |
| Lite판 출력 제한 | 현금출납부를 출력하려면 정식판이 필요합니다. |

## 3. 교육청 점검에서 실제로 보는 것

### 법적 근거 (확인한 범위)
- **학원법 제15조(교습비등)**: 교습비와 반환 사항을 학원 안 보기 쉬운 곳에 게시해야 합니다. 인쇄물·인터넷으로 광고하면 광고에도 표시해야 합니다. 등록·게시한 금액을 넘겨 받으면 안 되고, 위반하면 **과태료 300만원 이하**이며 등록말소나 교습정지까지 갈 수 있습니다.
- **학원법 제15조의3(장부·서류 비치)**: 원칙, 금전출납부, 교습비등 영수증 원부, 수강생대장, 직원 명부 등을 비치해야 합니다. 보존기간은 **시·도 교육규칙마다 다릅니다.** 검색으로 확인된 예는 원칙 준영구, 금전출납부와 영수증 원부 5년, 수강생대장은 1년~3년입니다. 관할 교육지원청 기준을 꼭 확인해야 합니다.
- **시행령 제18조 [별표 4] 반환기준** (교습기간 1개월 이내)

  | 시점 | 반환액 |
  |---|---|
  | 교습 시작 전 | 전액 |
  | 총 교습시간 1/3 경과 전 | 2/3 |
  | 1/2 경과 전 | 1/2 |
  | 1/2 경과 후 | 반환 없음 |

  1개월을 넘는 선납은 사유가 생긴 달에만 위 기준을 적용하고, 남은 달은 전액 반환합니다. 학원 사정으로 교습을 못 하게 되면 일할 계산해 반환합니다.
- **강사 채용**: 아동·청소년 성보호법에 따른 성범죄 경력 조회와 아동학대 전력 조회를 해야 하고(본인 동의서 필요), 교육지원청에 채용 사실을 통보해야 합니다.

### 2026년 서울 점검 위반 순위 (교습비 분야)
1. 교습비 변경 미등록: 52건
2. 교습비 표시·게시 위반: 42건
3. 교습비 외 비용 징수: 19건
4. 교습비 초과징수: 10건

→ **1위와 2위는 장부 도구와 홈페이지 게시로 대부분 예방할 수 있습니다.** 우리 도구는 이 둘을 가장 먼저 잡도록 설계했습니다.

## 4. 우리 도구: `tools/audit-ledger.html`

별빛 Lite 기능은 모두 포함했고(엑셀 일괄등록은 제외), 아래 기능을 더했습니다.

| 추가 기능 | 막는 위반 |
|---|---|
| 교습비를 **적용 시작월 + 교육청 등록일**과 함께 이력으로 관리하고, 수납은 해당 월에 적용되는 금액과 비교 | 변경 미등록, 과거 수납의 잘못된 불일치 표시 |
| 초과징수 입력 시 **경고창으로 확인을 받고**, 점검 목록에 '위반 우려'로 고정 | 초과징수 |
| 반마다 **실제 월 수업 횟수**로 일할계산 | 일할 금액 오류 |
| **법정 반환 계산기**(본인 포기 / 학원 사정, 여러 달 선납 포함) | 반환 부족 |
| **강사 명부**: 성범죄·아동학대 조회일, 교육청 통보일을 기록하고 누락이나 '채용 후 조회'를 경고 | 강사 채용 절차 위반 |
| 수강생대장 필수 항목(주소·전화) 누락 경고, 수납 기록이 있는 수강생은 삭제 차단 | 대장 부실, 보존 의무 |
| 영수증 원부, 금전출납부(전월 이월 포함), 강사 명부, 교습비 게시표를 **점검용 묶음으로 한 번에 출력** | 장부 미비치 |
| 장부 밖 **점검 체크리스트 12개**(등록증 게시, 교습시간, 선행학습 광고, 보험 등) | 기타 |
| **홈페이지 교습비 게시 코드 자동 생성** | 표시·게시 위반 |
| 백업 7일 경과 경고, CSV 내보내기 | 자료 유실 |

사용법: 파일을 크롬에서 열면 바로 쓸 수 있습니다. 데이터는 그 PC의 그 브라우저에만 저장되므로 매주 '백업 받기'를 누르세요.

## 5. 웨이메이커360 홈페이지 적용안

| 무엇을 | 어디에 | 공개 여부 |
|---|---|---|
| 교습비 안내 + 반환기준 | 홈페이지 '수강안내' 메뉴 | **공개 (법적 의무)** |
| 점검대비 장부 | 원장님 PC의 파일, 또는 홈페이지의 숨김 주소 | **비공개** |

**교습비 게시 넣는 법**
1. 장부의 [홈페이지 게시] 메뉴에서 기준월을 고르고 '게시용 코드 만들기'를 누릅니다.
2. '코드 복사' 후 홈페이지 편집기(아임웹, 윅스, 워드프레스 등)의 **HTML/코드 블록**에 붙여 넣습니다.
3. 교습비를 바꾸면 **교육청 변경 등록 → 장부 수정 → 코드 다시 붙여 넣기** 순서를 지킵니다.

게시 코드에는 반명과 금액만 들어가고, 학생 정보는 들어가지 않습니다.

**장부를 홈페이지에 심을 때 주의할 점**
- 방문자마다 자기 브라우저에 따로 저장되므로 서버로 개인정보가 새지는 않습니다. 대신 **다른 PC에서는 자료가 보이지 않습니다.** 여러 선생님이 함께 쓰려면 서버 저장(예: Google Sheets 연동)이 필요하고, 그때부터는 개인정보보호법상 안전조치(접근 권한, 암호화, 로그인)를 갖춰야 합니다.
- 공개 메뉴에 노출하지 말고, 검색 차단(`noindex`, 이미 적용됨)이 걸린 별도 주소에 두세요.

**확장 아이디어 (선택)**
별빛연구소처럼 '원장님용 무료 점검 도구'를 공개하면 동종 학원 대상 브랜딩이나 리드 확보에 쓸 수 있습니다. 다만 웨이메이커360의 고객은 학부모이므로 우선순위는 낮습니다.

## 6. 다음 단계 제안
1. 관할 교육지원청의 장부 보존기간, 영수증 서식, 교습시간 조례를 확인하고 체크리스트 문구를 맞춥니다.
2. 실제 반과 교습비를 입력해 1개월 시범 운영합니다.
3. 필요하면 엑셀 일괄등록(기존 원비 자료 이관)과 Google Sheets 동기화를 추가합니다.
4. 홈페이지 수강안내에 교습비 게시 코드를 넣습니다.

> 이 문서는 법률 자문이 아닙니다. 조문과 수치는 2026-09-30에 공개 자료를 검색해 확인했습니다. 시·도 교육규칙에 따라 다를 수 있으니 최종 판단은 관할 교육지원청 안내를 따르세요.
